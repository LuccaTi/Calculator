# Calculadora - The Odin Project

Este projeto é uma calculadora funcional criada como parte do currículo do "The Odin Project", na trilha fundamentos de desenvolvimento web. Foi um exercício prático para aplicar e consolidar os conhecimentos fundamentais de HTML, CSS e JavaScript.

## 🚀 Sobre o Projeto

O objetivo foi construir uma calculadora que realiza as operações aritméticas básicas, manipulando o DOM para criar uma experiência interativa para o usuário.

### ✨ Funcionalidades

-   **Operações básicas:** Adição, subtração, multiplicação e divisão.
-   **Botão de limpar:** Reseta o cálculo atual.
-   **Interface simples:** Um layout limpo e funcional.

### 🛠️ Tecnologias Utilizadas

-   HTML5
-   CSS3 (com Flexbox para o layout)
-   JavaScript (ES6+)

## 🧠 Aprendizados

Competências do projeto:

-   **Manipulação do DOM:** Selecionar elementos e atualizar dinamicamente o conteúdo da página.
-   **Event Listeners:** Capturar cliques nos botões para interagir com a calculadora.
-   **Lógica de programação:** Implementar a sequência de operações matemáticas.
-   **Estilização com CSS:** Utilizar Flexbox para organizar os elementos da calculadora de forma responsiva.
